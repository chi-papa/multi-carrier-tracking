# 発注・配送メモ

農業資材などの発注・配送状況をブラウザだけで管理できる、シンプルな静的Webアプリです。  
サーバー不要・インストール不要。`index.html` をブラウザで開くだけで動作します。

---

## 機能

- **発注登録** — 発注日・メーカー・商品名・数量・メーカー発送日・送り状番号・配送会社・ステータス・備考を一括登録
- **ステータス管理** — 未発送 / 発送済 / 到着 をワンクリックでサイクル変更。到着行は薄緑で表示
- **荷物追跡** — テーブル行・登録フォームの両方から追跡ページを直接開ける。trackings.jp 経由で14社対応
- **発送遅延アラート** — メーカー発送日から2日経過した未到着の行に警告バッジを表示
- **備考・送り状番号インライン編集** — テーブル上でクリックしてその場で編集・保存
- **フィルター＆検索** — ステータスフィルター / 商品名・メーカー・送り状番号のキーワード検索
- **メーカー管理** — 発注先メーカーの追加・削除（デフォルト9社プリセット済み）
- **配送会社管理** — 配送会社の追加・削除。trackings.jp IDを設定すると追跡リンクが有効になる
- **ユーザー名** — ヘッダーに担当者名を表示（複数人での運用を想定）
- **データ永続化** — すべてのデータはブラウザの `localStorage` に保存。サーバー通信なし

---

## 使い方

### 基本

```
index.html をブラウザで開く
```

以上です。ビルド・サーバー・依存パッケージは一切不要です。

### 荷物を追跡する

送り状番号が登録されている行は「追跡」ボタンをクリックすると追跡ページが開きます。  
登録フォームでも、送り状番号を入力すると「追跡」ボタンが表示されます。

### 配送会社の追跡IDを追加する

右パネル「配送会社管理」から会社名と trackings.jp ID を登録すると、その会社の「追跡」ボタンが有効になります。  
IDを空にした場合はGoogle検索にフォールバックします。

## ショートカット

| 操作               | 方法                               |
| ------------------ | ---------------------------------- |
| 発注を保存         | `Ctrl + Enter`                     |
| 備考を編集         | 備考セルをクリック                 |
| 送り状番号を編集   | 送り状番号セルをクリック           |
| 送り状番号をコピー | 送り状番号を右クリック             |
| ステータスを変更   | 「状態」ボタンをクリック           |
| レコードを編集     | 行をクリック（フォームに読み込み） |
| フォームから追跡   | 送り状番号入力後に「追跡」ボタン   |
